Find the tokens
that shouldn't exist.

A nonsense word seen once is a typo. A nonsense word echoed across fourteen independent artifacts is a codename — an internal service, a zombie endpoint, a credential fragment, a handle someone forgot to scrub.

seed = rarityz × log(1+count) × log(1+spread)

Install & run

# zero dependencies for the core miner
git clone https://github.com/toxicwind/seed-hunter && cd seed-hunter
python3 src/seed_hunter/seed_hunter.py /path/to/corpus --out out/

# NLTK semantic layer: PMI jargon, hapax credentials, coinages
pip install nltk
python3 src/seed_hunter/semantic_weirdness.py /path/to/corpus --out out/

# optional: cluster seed families with any embeddings endpoint
export SEED_EMBED_URL=… SEED_EMBED_KEY=…
python3 src/seed_hunter/nlp_cluster.py 80 out/seeds_v2.json

Why not just grep?

Grep finds what you already suspect. seed-hunter surfaces what you didn't know to suspect:

  • the internal canary header stamped on every HTTP response
  • the third-party marketplace codename hiding in a datasource roster
  • the access-key ID recurring across presigned URLs
  • the unreleased version tag that only exists in old package metadata

Design rules (learned the hard way)

rulereason
never train rarity on the scored corpusin-corpus training normalizes the jargon you're hunting
cap recurrence per fileone minified JSON repeats a token 100× and fakes popularity
spread > countsecrets echo across independent artifacts
filter noise shapesunicode escapes, base64 fragments, hex/uuid, CDN headers
